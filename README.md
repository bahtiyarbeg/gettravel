# GetTravel 🌍

Мультиязычный сайт для туристической компании **GetTravel** в Нячанге.  
Сайт включает:
- Главная страница с приветствием и баннером
- Каталог туров с карточками
- Страница бронирования с описаниями туров
- Страница контактов с телефонами, мессенджерами и картой
- Навигация (Navbar) и общий Layout
- Мультиязычность (en, ru, zh, vi, tr, ko, uz)
- TailwindCSS для современного дизайна
